## Projects

| Project | Description |
|---|---|
| [**oct-latent-diffusion-3d**](https://github.com/kushalX13/oct-latent-diffusion-3d) | 3D OCT latent diffusion model using an NV-Generate-style VAE + UNet with Rectified Flow in latent space. |
| [**medvitv2-medical-classification**](https://github.com/kushalX13/medvitv2-medical-classification) | KAN-integrated transformer for medical image classification — 97–98% accuracy on BloodMNIST and Czech WBC datasets. |
| [**RefineVL**](https://github.com/kushalX13/RefineVL) | Evaluation tooling comparing a baseline vision-language model (LLaVA-1.5-7B) against an HA-DPO-aligned checkpoint, with rubric-based automated judging and POPE hallucination benchmarking. |
| [**CarDiag-RAG**](https://github.com/kushalX13/CarDiag-RAG) | Hybrid retrieval system mapping vehicle symptom descriptions to NHTSA recall campaigns via dense + BM25 retrieval, score fusion, and cross-encoder reranking. |
| [**DriftGuard**](https://github.com/kushalX13/DriftGuard-AI) | Catches Terraform misconfigurations before apply — runs OPA/Conftest policies on plan JSON and emits PR-ready reports, with optional ML risk scoring. |
| [**QuakeScribe**](https://github.com/kushalX13/QuakeScribe) | Seismic analysis system that turns raw waveforms into AI-generated reports via signal processing, phase picking, and LLMs. |
